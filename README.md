Smart Retail Management System

A simple Smart Retail Management System built using HTML, SQL, and React Components.
This project includes features like invoice generation, sales reports, inventory tracking, and AI-powered business insights.

Features
Invoice Generation System
Generate customer invoices dynamically
Display customer details, products, quantity, and total price
Print invoices using browser print functionality
SQL query integration for fetching invoice data from database

Technologies Used
HTML
SQL
JavaScript

Reports Management
View total revenue
View total orders
Detect low stock products
Display recent sales history
Download/Print reports

Report Includes
Sales Report
Inventory Report
Low Stock Report

Database Query System
SQL queries are used to:
Fetch invoice information
Join customer, orders, and product tables
Generate sales reports
Store generated reports history

React Generic Components
GenericTableView
Reusable table component for:
Product tables
Orders tables
Customer lists
Inventory management

ReportsView
Interactive reports dashboard with:
Revenue calculation
AI-generated business insights
Product analysis
Loading states
Toast notifications

AI Insights Feature
Integrated AI-based analytics system using Gemini API.

Capabilities
Business performance analysis
Sales insights generation
Retail summary reports
Automated recommendations

# Product & Catalog Management Module

This branch contains the Product and Catalog Management part of the Smart Retail Management System.

## Features Implemented

- Product Table Creation
- Catalog Table Creation
- Product Insertion Queries
- Category Management
- Product Management
- SQL Relationships using Foreign Keys

## Files Included

### Catalog.sql
Contains:
- catalog table creation
- category data insertion

### Product.sql
Contains:
- products table creation
- foreign key relation with catalog
- sample product data insertion

## Technologies Used

- MySQL
- SQL Queries
- GitHub Version Control

## Database Tables

### catalog
Stores all product categories.

Fields:
- catalog_id
- category_name
- description

### products
Stores all product information.

Fields:
- product_id
- name
- sku
- category
- price
- description
- supplier_id
